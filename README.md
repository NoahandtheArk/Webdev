# The Storyteller - Lost TV Series Fan Website

A modern, interactive fan website dedicated to the iconic TV series "Lost". This project showcases the show's characters, episodes, and provides an engaging user experience for fans of the series.

# Features

- **Interactive Homepage**: Dynamic slideshow showcasing key moments from the series
- **Character Profiles**: Detailed information about main characters including Jack, Kate, Hurley, and Locke
- **Episode Search**: Search functionality to find specific episodes
- **Responsive Design**: Mobile-friendly layout that works across all devices
- **Save Functionality**: Ability to save favorite episodes and characters
- **Contact Form**: Interactive contact page for user feedback

# Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
- Responsive Web Design
- Modern CSS Grid and Flexbox layouts

# Getting Started

1. Clone the repository:

   ```bash
   git clone [your-repository-url]
   ```

2. Open `index.html` in your web browser to view the website.

3. No additional setup or installation required - the website runs entirely in the browser.

# Features in Detail

- **Dynamic Slideshow**: Auto-playing image carousel showcasing key moments from the series
- **Character Grid**: Interactive grid layout of main characters with detailed information

- **Responsive Navigation**: Mobile-friendly navigation menu
- **Save System**: Ability to save favorite content for later viewing
